This innovative project is a compact, custom instrument driven by an ESP32-S3 microcontroller that features capacitive touch keys instead of traditional mechanical keyboard switches. It incorporates two potentiometers and one rotary encoder for real-time parameter tweaking, alongside three toggle switches to seamlessly shift octaves or change musical play modes. Visual feedback is provided dynamically through three integrated LEDs. Because the design utilizes every single available hardware pin on the microcontroller, it relies entirely on its existing micro-USB port to transmit data rather than requiring extra audio outputs. By leveraging native USB MIDI capabilities, the device communicates directly with a computer or mobile phone to send instant, lightweight musical commands that trigger high-quality audio synthesis inside software like GarageBand or Ableton.
